# Editable course catalog

The initial snapshot comes from the public [Engosoft course shop](https://engosoft.com/shop) and its sitemap, retrieved on 2026-10-27. All 131 discovered product/course URLs appear in the admin library, including event, recorded-course and exam-simulator variants. They are catalog records, not 131 distinct curricula.

- 102 names and descriptions came from course pages.
- 20 additional names were verified from related-course cards on the website while their detail pages timed out.
- 9 entries have temporary names derived from their sitemap URLs. The import coverage panel lists them for review and links to each source.

Goals, audience and outcomes are **editorial suggestions**, generated by topic rules from the course name. They are not represented as verified syllabus statements. Some website tabs contained unrelated generic HVAC material, so the importer intentionally ignores those tabs. Every imported profile starts as suggested; an editor can change its name, category, description, audience, goals, outcomes, notes and URL, then save a draft or approve it.

Startup and the import button insert missing records without overwriting existing edits. The button also imports available Odoo catalog entries. Website recrawling is a separate explicit maintenance command; it is not a background scheduled job:

```sh
python -m venv /tmp/engosoft-catalog
/tmp/engosoft-catalog/bin/pip install -r scripts/catalog/requirements.txt
/tmp/engosoft-catalog/bin/python scripts/catalog/import-website.py
```

The snapshot is committed at `server/data/engosoft-website-courses.json`; source HTML remains outside the repository. Update the snapshot, review the diff, and restart/import to add newly found entries. Deliberately deleted imported records will be restored by the next insert-only import.

`/api/odoo/courses` searches the saved profiles immediately, even when Odoo is unavailable; remote next-run data refreshes in the background. Creation fills matching template fields and a caption from the selected profile, respects field lengths, and warns when the profile is still suggested. Picking another course clears fields tied to the previous source.
