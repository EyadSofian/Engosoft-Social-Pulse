# Reference Analysis

1. Keep provenance: source, capture date, campaign, platform and parent sheet.
2. Detect montage panels and crop each individual post before indexing. Review crop boundaries manually or mark `needs_review`.
3. Describe composition, subject, palette, density, typography hierarchy, CTA and logo treatment separately.
4. Tag content versus style so a retrieved automotive style cannot turn a BIM post into an automotive post.
5. Leave unknown performance and quality null. An unapproved or rejected image must not be promoted as a strong reference.
