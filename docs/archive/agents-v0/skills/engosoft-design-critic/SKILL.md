# Design Critic

1. Score subject fit, realism, composition and copy space, visual quality, and brand compatibility; each contributes 20 points.
2. Mark baked-in text/logos, deformed anatomy, wrong subject or missing text area as fatal.
3. For composed posts, additionally inspect hierarchy, Arabic rendering, overlaps, crop, CTA and locked logo.
4. Give concise evidence and one actionable revision. Do not call an image publish-ready just because the API succeeded.
5. Keep model score separate from a human 1–5 publishability assessment.
