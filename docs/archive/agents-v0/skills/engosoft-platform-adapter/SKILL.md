# Platform Adapter

1. Map selected platform to a named format in the central registry. Keep generation canvas size separate from final social dimensions.
2. Share verified facts, campaign idea and approved brand assets across variants.
3. Reflow headline, visual crop, text density and CTA according to platform and safe zones; never stretch a finished image blindly.
4. Keep platform-local edits local while global fact changes propagate everywhere.
5. Validate each exported variant independently.
