# Engosoft video creative

Status: planning contract only. Do not build the full video system until the image vertical slice (CFM webinar, course launch, engineering educational post) passes evaluation.

Shared with images: `CreativeBrief`, reference library, brand engine, asset library, creative director, fact validator, version history.

Pipeline:

```
prompt → creative strategy → storyboard → scenes → assets → motion → voice → music → render
```

## Rules

1. Storyboard first: scenes with duration, purpose, on-screen copy (canonical, live), motion and audio notes.
2. The official logo is a locked overlay from `brand/logos/`; never generated in frames.
3. Facts on screen are verified like image facts.
4. Course lifecycle formats from the business plan: one-week-before teaser, first-lecture Zoom highlight, closing review video, certificate/achievement reel.
5. Review renderer and music/voice licensing before choosing a tool.
